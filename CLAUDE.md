# CLAUDE.md — vodiyhouse.uz · Проект-1 (v2, правила скорости)

## Суть
Vodiy House — агентство новостроек в Фергане. Публичный каталог ЖК (/uz по умолчанию, /ru) + кабинет /admin (на русском).
Шахматки нет (решение заказчика 06.10.2026) — не добавлять, даже если встретится в ТЗ или старых заметках. Наличие — простой список квартир со статусом «свободна / бронь / продана» в админке ЖК.
Стек: Next.js 16 App Router, TypeScript strict, Tailwind + shadcn/ui, Supabase, Netlify, next-intl.
Правило ТЗ 1.2: в публичной части нет ни одного контакта застройщика — все кнопки связи ведут на Vodiy House.
Что читать: PROGRESS.md «Сейчас» → раздел текущей фазы в PLAN.md → мокап docs/mockup/ и docs/vodiy-house-mockup.md → ТЗ. При расхождении: правило 1.2 → мокап → PLAN.md → ТЗ. Старые логи docs/progress/ — только когда нужно старое решение.

## Команды
npm run dev · lint · typecheck · test · e2e:1440 -- <спека> · e2e (полный, 390 + 1440 — только на приёмке фазы) · db:push · demo:seed

## Как работаем
- Одна фаза, последовательно, в main. Одна сессия Claude в папке проекта. Без worktree и без агентов, которые пишут код.
- Шаг сделан = lint, typecheck, юниты затронутого модуля и одна e2e-спека на 1440 зелёные. Больше ничего.
- Блок (2–4 шага) готов = спеки блока на 1440 + ревью одним агентом в один круг (только чтение). Чиним баги, права, деньги, нарушения ТЗ и 1.2; мелочи → «Полировка» в PROGRESS.md.
- Фаза принята = полный e2e 390/1440, скриншоты против мокапа одним прогоном, «Полировка» закрыта пачкой. Lighthouse — один раз перед запуском.
- Нет мутационных проверок, прогонов ×10 и второго круга ревью. Исключение: миграции и lib/calc — второй агент один раз.
- Новых стендов /dev не делать: кабинет проверяем на настоящих страницах с DEMO в облаке.
- Флак — один перезапуск; не повторился → запись в «Полировку», шаг не стоит.
- Застрял дольше 30 минут — две строки в PROGRESS.md, что пробовал, и следующий шаг плана.
- Реальные данные не выдумывать: нет данных → заглушка TODO-заказчик, работа продолжается.

## Дизайн
Мокап — ответ по умолчанию: делать как в мокапе без вопроса (структура и функции; визуал — свой лучший вариант в стиле мокапа).
Мокап молчит → реши сам, одна строка в docs/design-decisions.md. Интервью не проводим.
Вопросы — только деньги, формулы и данные ЖК, пачкой в конце шага; работу в ожидании ответа не останавливать.

## Код
- БЭМ: .block, .block__el, .block--mod. Один компонент — папка с .tsx, .css, index.ts; CSS подключается через @import в app/globals.css. Tailwind — только раскладка и отступы.
- Токены — styles/tokens.css. Деньги — lib/calc и lib/format. Тексты — messages/ru.json, messages/uz.json.
- Имена предметные, на английском. Лимиты длины функций и файлов — предупреждение ESLint, не повод для рефакторинга до запуска.
- prettier — только по изменённым файлам, никогда по папке.

## Анимации
Два режима через <html data-motion="full|lite">, старт в lite, prefers-reduced-motion → none. Только transform и opacity.
Автоопределение уже сделано в lib/motion/ — не переписывать. Новая анимация = два CSS-варианта под [data-motion].
Ручной переключатель для тестов: ?motion=full|lite|none (none — как reduced-motion: без анимаций, первый экран — только постер).
