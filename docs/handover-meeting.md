# Сдача Проекта-1: встреча с заказчиком и «сделать руками» (02.11.2026)

Прод — `docs/prod-setup.md` (аккаунты исполнителя, ветка `release/project-1`). Что нужно от заказчика — `docs/handover-client.md`. Полный чек-лист — `docs/progress/phase-6-handover.md` (п. 3–4).

## Сценарий встречи (~40 мин)

1. **Сайт пустой — так и задумано.** Открыть прод с телефона: «Скоро здесь появятся новостройки», форма подбора, «О нас», «Как купить». Ни одного выдуманного ЖК, цены или телефона.
2. **Пример заполненного сайта** — тестовый деплой https://vodiyhouse-test.netlify.app. Сказать прямо: **данные там вымышленные (DEMO)**, это витрина возможностей, не прод.
3. **Руководитель.** Исполнитель в **своём** терминале (не агент — временный пароль печатается):
   ```bash
   cd C:\Users\Alocomputers\Desktop\VH_release\apps\site
   node --env-file=.env.prod scripts/staff-create-head.mjs --email <email руководителя> --name "<Имя>"
   ```
   Пароль — руководителю лично. Он входит на `<прод>/admin/vhod`, задаёт свой пароль (от 10 знаков).
4. **Контакты и курс.** Руководитель: «Настройки → Контакты» — телефон Vodiy House; «Программы оплаты» → «Зафиксировать курс».
5. **Публикация ЖК.** Руководитель открывает Shodlik (или другой ЖК, по которому заказчик подтвердил данные) → «Для публикации: 6 из 6» → застройщик MYB опубликован → «Опубликовать» с галочкой правила 1.2. На сайте с телефона: ЖК в каталоге, страница ЖК, «осталось N», расчёт, ни одного контакта застройщика.
   - Если заказчик не готов публиковать настоящий ЖК — не публиковать, сайт остаётся пустым; показать «Предпросмотр» в кабинете.
6. **Заявка с телефона.** На сайте «Подберём вручную» → имя и телефон (настоящий, заказчика) → номер заявки **#1001** → в кабинете «Заявки». Telegram и Таблица — после бота и Таблицы заказчика.
7. **Сотрудники.** Руководитель сам создаёт менеджера и мобилографа («Настройки → Сотрудники»).
8. Передать `docs/head-guide.md`, `docs/manager-guide.md`, `docs/handover-client.md`, `docs/texts-for-approval.md`.

После встречи: `node --env-file=.env.prod scripts/cloud-check.mjs --prod` — DEMO нет, сотрудников e2e нет, заявки — только настоящие.
