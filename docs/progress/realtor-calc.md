## Решения исполнителя (реши сам)
- Значения по умолчанию: 600 млн сум, взнос 120 млн (20 %), 15 лет, 17,5 % (нижняя граница ипотеки на первичке по uysot 04.11), рассрочка 24 мес. без наценки, платёж для подбора 8 млн. Валюта по умолчанию — сум.
- Наценка рассрочки — % на остаток за весь срок (как у программ застройщика), не годовая.
- Дифференцированный в «Сколько могу купить» — по первому (самому большому) платежу.
- Взнос > 90 % — считаем 90 % и пишем это под полем (как у квартиры: выше — уже не кредит).
- Смена валюты ввода пересчитывает суммы в полях по курсу и ставит ту же валюту итога; без курса переключателей нет.
- Старые ссылки `?developer=…&program=…&down=…` не перенаправляем: калькулятор открывается со значениями по умолчанию (ключ `down` больше не читается — взнос теперь суммой в `first`).
- CSS калькулятора — в бандле `calc.css` (как раньше у /kalkulyator); отдельный лёгкий бандл — в «Полировку».
- `markCalcNavigation` в useCalcParams остался без вызовов — убрать в «Полировке».
