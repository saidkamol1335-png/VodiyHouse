## Решения исполнителя (реши сам)
- Значения по умолчанию: 600 млн сум, взнос 120 млн (20 %), 15 лет, 17,5 % (нижняя граница ипотеки на первичке по uysot 04.11), рассрочка 24 мес. без наценки, платёж для подбора 8 млн. Валюта по умолчанию — сум.
- Наценка рассрочки — % на остаток за весь срок (как у программ застройщика), не годовая.
- Дифференцированный в «Сколько могу купить» — по первому (самому большому) платежу.
- Взнос > 90 % — считаем 90 % и пишем это под полем (как у квартиры: выше — уже не кредит).
- Смена валюты ввода пересчитывает суммы в полях по курсу и ставит ту же валюту итога; без курса переключателей нет.
- Старые ссылки `?developer=…&program=…&down=…` не перенаправляем: калькулятор открывается со значениями по умолчанию (ключ `down` больше не читается — взнос теперь суммой в `first`).
- CSS калькулятора — в бандле `calc.css` (как раньше у /kalkulyator); отдельный лёгкий бандл — в «Полировку».
- `markCalcNavigation` в useCalcParams остался без вызовов — убрать в «Полировке».

## Анимации и дизайн (PLAN §10, п. 49; интервью 04.11 — «по рекомендациям»)
- A1. `components/RollingNumber`: сумма итога катится по разрядам (лента 0–9 сдвигается transform, 0,45 с) — только full; lite — новое число проявляется; none — сразу. Ленты и знаки рисует CSS (`content`), в узле одна строка суммы (`sr-only`) — диктор, копирование и тесты читают её. CalcTotal: необязательные `lively` (перекат + подсветка изменившейся строки) и `figure`; у расчёта квартиры цифры по-прежнему не анимируются.
- A2. `RealtorCharts`: полоса «Из чего складывается выплата» (взнос · тело кредита / остаток · проценты / наценка; доли — scaleX от начала своей доли) и «Остаток долга» столбиками (годы при сроке > 36 мес., кварталы > 25, иначе месяцы; scaleY; role="img" со сводкой).
- A3. Вкладки: графитовая подложка переезжает к выбранной (translateX + scaleX от меры кнопки, пружина в full); до меры и без JS подложку рисует сама вкладка. Смена вкладки — шаги входят по очереди сдвигом и проявлением (lite — проявление). Вход страницы — вкладки, итог, график следом за шапкой (как SiteMotion, только пока вход не сыгран).
- A4. Ползунок срока: подсказка со значением над бегунком при перетаскивании и фокусе с клавиатуры, бегунок ×1,2; кнопки взноса, сроков и вкладки «вжимаются» (scale 0,95) в full.
- Реши сам: легенда полосы — только доли (суммы — строками итога ниже: иначе итог выше экрана 900 px); итог на экранах ≥ 880 px высотой без своей прокрутки (дробная высота крупной суммы давала пиксель переполнения и полосу).
