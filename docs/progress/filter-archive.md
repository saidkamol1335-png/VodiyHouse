# Архив кнопок фильтра сайта (06.11.2026)

Запрос заказчика: «добавь функцию добавления в архив — админ на какой-то период может скрыть некоторые кнопки» фильтра каталога.

## Ответы заказчика (06.11)
- Что скрывать: отдельные кнопки **и** блоки целиком; районы и застройщики в выпадающих списках — тоже.
- Период: только вручную — кнопка в архиве, пока её не вернут.
- Кто: руководитель **и** менеджер.
- Где: «Настройки → Фильтр сайта» (`/nastroyki/filtr`).

## Как устроено
- Публичная запись `settings` `site.filter_archive` = `{ items: [{ id, at }] }`; id — `section:<блок>` или `<блок>:<значение>` (`payment:mort`, `rooms:0`, `deadline:2028`, `developer:<slug>`…). Модель — `packages/shared/src/filterArchive.ts`.
- Сайт: `lib/site/filterArchive.ts` (public_settings, кэш с `SITE_SETTINGS_TAG`) → главная и /novostroyki → `CatalogFilter` не рисует скрытые кнопки; блок без кнопок пропадает.
- Кабинет: `FilterArchiveBoard` — кнопки по блокам как на сайте (каталог через `site_catalog`), клик — в архив / вернуть, ниже список архива; действие `setFilterArchiveAction` → `expireSiteSettings()` (сайт обновляется сразу).
- Миграция `20261106120000_filter_archive.sql`: менеджеру — insert/update только этой записи и только публичной. **06.11 по «да» заказчика — в тестовом облаке** (одной транзакцией + запись в `supabase_migrations.schema_migrations`, без `db:push`: тот прихватил бы ещё не одобренную `20261103210000_reviews.sql`). Прод не менялся. Следствие: отзывы теперь старше последней применённой — их `db:push` пойдёт только с `--include-all`. Имена политик Postgres обрезал до 63 байт (кириллица) — на работу не влияет.

## Решения исполнителя
- Архив прячет кнопку, но не трогает выдачу: ссылки рекламы застройщика, вкладок «Выберите квартиру», квиза и подборок ведут на обещанное. Выбранная кнопка из архива видна, чтобы её можно было снять (`withActive`, ревью).
- «Istalgan» (любой срок) в архив не уходит — это сброс, а не выбор; блок срока без других кнопок не показывается. Цена — только блоком целиком.
- Запись — с проверкой версии `updated_at` и 3 попытками: одновременные правки двух сотрудников не затирают друг друга; 0 строк при той же версии = «нет прав». Архив ≤ 200 записей.
- Кнопка из архива, которой уже нет в каталоге (застройщик снят, год прошёл), остаётся в своей группе в кабинете — её можно вернуть.
