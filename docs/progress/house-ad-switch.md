# Выключатель своей рекламы Vodiy House (06.11.2026)

Запрос заказчика: «добавь раздел для добавления рекламы на сайт или удаления». Раздел уже есть — «Витрина → Реклама» (`/vitrina/reklama`, ТЗ 5.4, мокап): реклама застройщиков — добавить, порядок, период, удалить. Баннер со скриншота заказчика — «своя реклама Vodiy House» (`houseAd`, коммит `966ed2b`): сайт собирает её из каталога, пока у застройщиков нет действующей рекламы; управлять ею было нельзя.

Ответ заказчика (06.11): «Выключатель» — в «Витрина → Реклама» карточка «Своя реклама Vodiy House» с тумблером «Показывать на сайте».

## Как устроено
- Публичная запись `settings` `site.house_ad` = `{ enabled }`; записи нет — включена (как до выключателя). Модель — `packages/shared/src/houseAd.ts`.
- Сайт: `lib/site/houseAd.ts` (public_settings, кэш `SITE_SETTINGS_TAG`) → `HomeOffers`: реклама застройщика, иначе своя — только если включена; иначе блока рекламы нет (на якорь `#reklama` ссылок нет).
- Кабинет: `HouseAdPanel` над очередью рекламы — пояснение, тумблер, «Сейчас на главной — …» (первая действующая реклама застройщика по порядку, иначе своя или «блока нет»), ссылка на главную. Действие `setHouseAdAction` — только руководитель (как вся «Витрина»), RLS settings уже это требует — миграция не нужна.
