Тест, которому нужна новая отметка времени в одной транзакции файла, сдвигает старую назад (`now()` в ней стоит) — как «Условия актуальны на» в `payment-programs.test.ts`.
- Сверка схемы облака с PGlite (2.9б, разовый скрипт сессии, только чтение): функции, колонки, ограничения, индексы, политики, триггеры, RLS, права на таблицы и функции, enum — 0 расхождений. Шум: PGlite хранит NOT NULL как ограничения (`*_not_null`); в облаке есть `public.rls_auto_enable()` — событийный триггер Supabase `ensure_rls` (сам включает RLS на новых таблицах), через API не вызывается.
- Подключение `pg` к облаку — только через `dbClientConfig` (`lib/supabase/dbClient.ts`): TLS по умолчанию; `sslmode` в адресе важнее.
- Фокус после исчезнувшей кнопки: `useFocusAfterRender()` (`lib/ui`) — «поставь фокус на id после перерисовки»; отказ формы по полю — `useFocusFirstInvalid()` (тот же модуль): фокус — эффектом после коммита самого запроса (запрос перерисовывает владельца), после очистки `useRefocusAfter`.
- `Button` пропускает только объявленные aria-атрибуты: дефисные пропсы TypeScript не проверяет, и необъявленный молча уходит в `...look`. Новый — объявить и передать.
- `<details>` (и другие блочные) внутри `<p>` HTML не допускает — гидратация падает; такие строки — `<div>`.
- e2e: имя `<select>` внутри `<label>` включает выбранный вариант («Подъезд Подъезд 2») — `getByLabel(/^Подъезд/)`, а не `exact: true`.
- Док «Квартир» ищет хозяина по `[data-units-dock-host]` (блок со списком и блок без списка), а не по классу чужого блока.
- e2e: статус 404 проверять `page.request.get(…)`, а не `page.goto` — страница 404 в разработке пишет в консоль свои предупреждения. Скриншот до гидратации даёт «hydration mismatch» (Playwright прячет курсор стилем `caret-color`) — перед `screenshot` ждать `networkidle`. На холодном кэше Turbopack `screens.spec.ts` (`/admin/vhod`, `/dev/parol`) пишет его в лог сервера 5–8 раз за прогон, и `networkidle` не спасает (проверено 22.10.2026) — страницы не виноваты, проверки консоли зелёные; разобрать на приёмке фазы (шаг 14).
