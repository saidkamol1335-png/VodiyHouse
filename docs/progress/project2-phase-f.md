## Решения исполнителя
- Фаза названа F (буквы Проекта-2), а не 6.
- Перенос release (п. 43): `prod-up.mjs` и `prod-token.ps1` не перенесены — они поднимают прод Проекта-1 (один сайт); их заменяет `docs/launch.md`, исходники — в истории `release/project-1`. Памятки и чек-лист из release не переносились построчно — переписаны (F6, F7). Незакоммиченное в `VH_release` (первый экран «Ufq», скин) не трогалось.
- Тёмный первый экран (п. 45): в `main` он живой (светлый «Ufq» не закоммичен) — убирать нечего; уборка — вместе с переносом «Ufq».
- Telegram вне прода: заглушённая отправка отвечает «не ушло» (`muted`), а не «ушло» — заявка остаётся в очереди, если флаг когда-нибудь попадёт не туда.
- Метка сотрудника: не httpOnly (сайт читает её и в браузере для пикселей), срок 400 дней, снимается только выходом; заявки и старты Telegram сотрудника пишутся как обычно (это записи, не статистика) — конверсия «визиты → заявки» у сотрудников смещена.
- CSP: `style-src` остаётся с `'unsafe-inline'` (style="…" в серверной разметке); `global-not-found` статичный — его скрипты без nonce блокируются, страница 404 работает простой ссылкой.
- «Ход стройки»: основные числа — отчёты блоков, видео квартир — отдельной строкой; ожидание — по всем отчётам, часы на часах (ночи и выходные входят); снятый и опубликованный снова — не ожидание; «без отчёта» — месяц конца периода, по нынешнему списку строящихся блоков; ЖК-черновики и скрытые — в списке (как в «Заданиях»); «45+ дн.» считает база.
- Памятки: текст — в коде кабинета, файлы `docs` собираются из него; руководителю — вкладки с памятками менеджера и мобилографа (вводит сотрудников в работу); менеджер и мобилограф видят только свою. Старые скриншоты Проекта-1 из памятки руководителя убраны.
- Репетиция — PGlite в памяти (Docker и pg_dump на ноутбуке нет): прод только читается одной транзакцией «только чтение», выводятся только числа.
- Второй руководитель (L8): имени исполнитель не дал — «Ibrokhimov» (меняется в «Настройки → Сотрудники»); пароль выбран исполнителем, поэтому смена при первом входе не требуется (`must_change_password = false`); второй фактор (Telegram) обязателен как у всех.
- e2e «К1.2 карточка не мигает» падает и без изменений фазы F (проверено откатом файлов CSP) — старый пункт «Полировки».
