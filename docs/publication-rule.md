# Правило публикации ЖК и квартир — v2 (01.11.2026)

## Три состояния ЖК
- Черновик — нет хотя бы одного пункта минимума ЖК. На сайте нигде: не в каталоге, не по ссылке (404), не в sitemap. В кабинете: «Для публикации: N из M» + «Не хватает: …».
- «Скоро» — минимум ЖК есть, но ни одной полной квартиры. На сайте: карточка с меткой «Скоро» + страница без планировок и расчёта, с блоком «Скоро».
- Полный — минимум ЖК есть и ≥ 1 полная квартира. Обычная страница, показываются только полные квартиры.
Состояние считается автоматически при каждом сохранении: первая полная квартира → Полный; исчезла последняя → Скоро. Руководитель нажимает «Опубликовать» один раз (с отметкой правила 1.2), дальше ЖК переключается сам. Убрать обязательный пункт у опубликованного ЖК нельзя — кабинет просит сначала «Скрыть».
Архив для неполного не используется. Неполные ЖК и квартиры нигде не удаляются.

## Минимум ЖК
1. Название ru/uz и адрес · 2. Точка на карте · 3. Опубликованный застройщик · 4. Общие рендеры ЖК: обложка ≥ 2400 px и ещё ≥ 4 (фасад, двор, вид сверху; рендеры квартир не считаются) · 5. ≥ 1 блок со сроком сдачи · 6. Программа оплаты застройщика и записанный курс ЦБ.
Без рендеров ЖК на сайт не выходит ни в каком виде.

## Полная квартира
Планировка с чертежом ≥ 1200 px, комнатами и площадью + хотя бы одна квартира этой планировки с ценой и статусом «в продаже». Рендер интерьера и видео — по желанию.
Неполная планировка: на сайте нет нигде (список планировок, расчёт, фильтры, ответы API). В кабинете остаётся с меткой «Не хватает: цена · чертёж · площадь», фильтр «Только неполные», у ЖК — «Полных квартир: k из n».

## A — База
Функции полноты complexCompleteness() и layoutCompleteness() со списками «Не хватает»; состояние ЖК draft / soon / full; site_*-представления отдают только полные планировки и квартиры; запрет удаления обязательного у опубликованного ЖК.

## B — Сайт
- Каталог: карточка «Скоро» — метка на обложке, «Цены скоро · позвонить» вместо «Платёж от», в конце списка. Фильтры по цене, комнатам и площади её не показывают. На главной в «новых» и подборках по фильтру — нет; в ручной подборке — только если руководитель добавил сам. Счётчики застройщика считают её опубликованной.
- Страница ЖК «Скоро»: вместо планировок и расчёта блок с текстом ru/uz: «Планировки и цены скоро появятся на сайте. Чтобы узнать условия сейчас, позвоните в Vodiy House: {общий номер из настроек, тот же что в шапке}». Только телефон, без формы. Остальные разделы — как обычно, пустые скрываются.
- Фасад и план этажа: квартиры неполных планировок — серые, без цены, по нажатию «Цена уточняется — позвоните в Vodiy House» + общий номер, без формы. Блок без полных квартир — серый с меткой «Скоро», не кликается. «Продано» и «бронь» — как сейчас.

## C — Кабинет
Статус-колонка: Черновик (N из M) · Скоро · Опубликован · Скрыт · Архив. Карточка ЖК: «Не хватает: …» со ссылками на шаги мастера; «Полных квартир: k из n». Планировки: метка и фильтр «Только неполные». Чек-лист «8 из 8» разделить: минимум ЖК → кнопка «Опубликовать»; полнота квартир — отдельно, на публикацию ЖК не влияет.

## D — Материалы
content:import заливает черновиками всё, что есть, включая ЖК без застройщика (San'at Saroyi, Dream Residence, Soy Bo'yi Avenue, Chinor Residence, Garant Avenue): застройщик у черновика может быть пустым, обязателен только для публикации.
