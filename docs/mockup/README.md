# docs/mockup — живой мокап Проекта-1

Эталон дизайна. Источник — холст «Vodiy House — живой прототип · Проект-1»: https://claude.ai/artifact/BwQ3UuvBPVvwVjYkkaRVhz (версия `1791652656-c10d`, обновлён 10.10.2026; выгружено 19.10.2026).

## Что здесь

| Папка | Что внутри | В git |
| --- | --- | --- |
| `source/project/` | 54 артборда холста (`*.dc.html`), `canvas.json` (раскладка и подписи), `support.js` (рантайм холста, включает React 18) | да |
| `source/_blob/` | 169 ассетов: фото ЖК (WebP), карта офиса (SVG), CSS мокапа (`a8c8…` — десктоп и кабинет, `64c3…` — телефон) | да |
| `tools/` | `serve.mjs` — локальный сервер мокапа, `capture.mjs` — съёмка всех артбордов | да |
| `screens/` | 83 скриншота 1440 и 390 (~40 МБ), `INDEX.md` со списком | нет — пересобираются за ~12 мин |

Основные исходники: `Main.dc.html` — сайт и кабинет 1440 (один прототип), `Mobile.dc.html` — телефон 390. Остальные артборды — обёртки, которые открывают нужный экран через атрибуты `start-*`.

Группы скриншотов: `site-1440` (12), `cabinet-1440` (7), `dark-1440` (3), `adaptive-390` (7, сжатый десктоп), `phone-390` (25, отдельный мобильный дизайн).

## Как открыть и переснять

```bash
node docs/mockup/tools/serve.mjs
```

Мокап открывается на http://localhost:4599/project/Main.dc.html (любой артборд — по имени файла). React и шрифты грузятся из интернета (jsdelivr, Google Fonts).

```bash
node docs/mockup/tools/capture.mjs
```

Нужен `playwright` (появится в devDependencies на фазе 0). Второй аргумент — фильтр по имени: `node docs/mockup/tools/capture.mjs 4599 "^Cab"`.

## Если холст обновился

Выгрузить заново через инструмент Artifact (`read` с `paths` для `project/*.dc.html`, по одному `path` на ассет `_blob/<id>`), положить в `source/`, переснять скриншоты и записать новую версию в этот файл.

## Важно

Данные мокапа вымышленные (ЖК, цены, люди, телефоны) — в продакшен не переносить. На части фото — водяные знаки сторонних сайтов (`TODO-заказчик`). Демо-панель сверху (Сайт / Кабинет, Светлая / Тёмная) — только для прототипа.
