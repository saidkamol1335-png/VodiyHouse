# П. 2 — тексты первого экрана главной: варианты на выбор (к 19.11)

Заказчик: заголовок короче — **максимум одна строка**; сразу под ним — одна строка вроде «Vodiy House portalida: narx quruvchinikidek, tanlash va ko‘rish…» вместо длинного текста. Три галочки под заголовком («Narx — quruvchinikidek», «Tanlash va ko‘rsatish — bepul», «TJM hujjatlari tekshirilgan») уходят в эту строку, их место занимают цифры «N turar-joy majmuasi · N quruvchi · N kvartira sotuvda» (п. 1).

Сейчас: «Farg‘onadagi yangi binolarda kvartiralar — quruvchi narxida» (60 знаков) + «Vodiy House ishlaydigan barcha turar-joy majmualari: quruvchi narxlari, bo‘sh kvartiralar va tekshirilgan hujjatlar.» / ru «Квартиры в новостройках Ферганы — по цене застройщика» + «Все ЖК, с которыми работает Vodiy House: цены застройщика, наличие квартир и проверенные документы.»

Янтарём выделяется вторая часть заголовка (после «—»), как сейчас.

| | Заголовок (одна строка на 1440) | Строка под ним |
|---|---|---|
| **A — цена** (рекомендую) | uz: Farg‘ona yangi uylari — **quruvchi narxida** (40) | Vodiy House portalida: narx quruvchinikidek, tanlash va ko‘rsatish — bepul. |
| | ru: Новостройки Ферганы — **по цене застройщика** (42) | На портале Vodiy House: цена как у застройщика, подбор и показ — бесплатно. |
| **B — выбор** | uz: Farg‘onada **yangi uy tanlang** (27) | Barcha TJMlar bir joyda: quruvchi narxlari, bo‘sh kvartiralar, tekshirilgan hujjatlar. |
| | ru: Выберите **новостройку в Фергане** (30) | Все ЖК в одном месте: цены застройщика, свободные квартиры, проверенные документы. |
| **C — без переплаты** | uz: Yangi uy — **ortiqcha to‘lovsiz** (29) | Vodiy House: ustama 0%, hujjatlar tekshirilgan, tanlash va ko‘rsatish bepul. |
| | ru: Квартира в новостройке — **без переплаты** (38) | Vodiy House: наценка 0 %, документы проверены, подбор и показ — бесплатно. |

**Почему A:** сохраняет главное обещание созвона («narx quruvchinikidek») и почти дословно берёт строку заказчика; 40 знаков помещаются в одну строку на 1440 и в две — на телефоне 390. **B** — короче всех, но цена уходит из заголовка в строку. **C** — сильнее звучит, но «0 %» без пояснения заказчик на созвоне назвал непонятным (п. 6).
