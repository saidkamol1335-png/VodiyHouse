# Лендинг Vodiy House: CGI-таймлапс стройки ЖК по скроллу (обновлено 14.10.2026)

Три варианта главной. Первый экран — фотореалистичный CGI-таймлапс стройки ЖК Nurli Vodiy, который проигрывается скроллом: участок → котлован → фундамент → каркас с кранами → фасад и окна → кровля → двор → вечер, свет в окнах → облёт. Ролик отрендерен в Blender (Cycles, 208 кадров 1280×720) по рендеру заказчика — две белые башни, тёмная вставка, лобби с козырьком, двор — в окружении Ферганы: махалля с дворами за дувалами, панельные кварталы, сады, тополя вдоль полей, горы в дымке. Запасной движок — та же стройка на Three.js (`data-build-engine="3d"`). Код по БЭМ, архив `vodiy-house-3-varianta.zip` (README внутри), отдельно — ролик MP4 (15 с, с финальной плашкой Vodiy House).

- «Закат» — тёмный, кино: буквы «ваш дом» за растущими башнями и кранами (маски из рендера), плеер таймлапса, экскурсия, вечерний финал под формой. https://claude.ai/artifact/UEmSm4W7YBDKKK3ZeAefhD
- «Свет» — светлый, по ТЗ: текст и этапы слева, ролик в рамке «плеера» справа. https://claude.ai/artifact/GK1R8iW14dsFzy61Hkh9AL
- «Чертёж» — синька: рамка листа и штамп; первый кадр тонирован «синькой» с сеткой и с первых шагов скролла оживает в цвете. https://claude.ai/artifact/TGYCM7Vq47XLr24sSskgFz

Как устроено: кадры WebP (~15 МБ на ролик, до показа страницы грузится ~2 МБ — каждый 8-й кадр, остальное в фоне), проигрыватель `assets/js/video/FrameSequence.js` с плавным переходом между кадрами; на вертикальных экранах кадр сдвигается так, чтобы дом оставался в кадре. Перерендер — `tools/cgi/scene.py` (Blender 4.5) + `pack_web.py` и `make_video.py`, команды в README. Тайминги этапов в ролике совпадают с `timeline.js`.

Общее: прелоадер в духе buttermax (знак собирается из блоков и открывает сайт), параллакс-слои как у wearebrand, переходы и проявление текста как у oryzo, 3D-скайлайн продаж (contribution-skyline), колесо ЖК (works-wheel). Цвета — по ТЗ (#F89B0D, #050505, Manrope).

Вариант ещё реалистичнее — AI-видео по рендеру заказчика (Higgsfield): нужен платный тариф, ~80+ кредитов; на бесплатном аккаунте 0 кредитов.

Демо: ЖК, цены, цифры, телефон и Telegram условные. Фото ЖК — из папки заказчика (снимки с водяными знаками не использованы); перед запуском — официальные рендеры застройщиков.
