## Решения при переносе (реши сам)

- Дата проверки документов и визита сотрудника в чек-листе не указана: взята дата записи в чек-листе (Shodlik 15.10, Sayilgoh 25.10 и 18.10). Где даты нет, визит пуст и документы не отмечены (Ibrat 14).
- Документ отмечен проверенным, только если есть файл на Drive. «Сейсмостойкость 8 баллов» без файла — в текстах, не в документах.
- Sayilgoh: цена за м² — по этажам из чек-листа (решение руководителя 18.10), пентхаус — по нижнему уровню. Статусы, номера и площади — со снимков шахматки: в площади уже есть часть балконов и террас. Цены квартир на снимках другие (см. вопрос 5), на сайт не идут.
- Shodlik: цена — за м² по этажу. В таблице нет номеров квартир: номер на сайте и в кабинете — «этаж-стояк». Для `83,47 м²` (блок A, 8 этаж, свободна) и всех проданных без подписи число комнат не указано — квартира есть в списке без планировки, в типах на сайте её нет.
- Shodlik: взнос «больше 50 %» в программе — ступень от 51 %, срок на ней до 12 мес.
- Chinor: цена 9 900 000 сум за м² из шахматки, не «от 8 900 000» из пункта «Цена»: на сайте цена не окажется ниже настоящей. Блоки — A, B, C1, C2, C3 из шахматки. Потолки 3,0 м — минимум по жилым этажам. Срок — по госреестру.
- Garant: планировки без привязки к подъездам — все в блоке A, цена «от» по 8 000 000 сум за м². Срок — 1 кв. 2027 со слов застройщика, в госреестре 14.07.2027.
- Ibrat 14: цена по обычному прайсу 6 500 000 сум за м², акция в цену не включена; двухуровневые квартиры не внесены (нет числа комнат).
- Ibrat 14: блок назван «4–5» (в чек-листе кадастр по 4-му и 5-му), сколько блоков всего — неизвестно.
- Адрес — без города (город показывает сайт), ориентир сокращён до 50 знаков. Программы черновых застройщиков выключены: включает руководитель при публикации. Ипотека не внесена: нет ставок и сроков.
- Chinor «Комфорт+» — класс «Комфорт» (другого значения в базе нет), «+» — в тексте. «Удобство локации»: университет — вид «Школа», аптека и роддом — «Поликлиника», San'at Saroyi — «Парк»; Центр госуслуг и Центральный банк не внесены: нет подходящего вида.
- «Центр города» в блоке «Удобство локации» — без подписи «на машине»: в чек-листе время до центра пешком.
