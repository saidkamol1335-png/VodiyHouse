# Дизайн-решения

Решения дизайн-интервью (CLAUDE.md §2), чтобы не спрашивать дважды. Вариант по умолчанию — мокап (`docs/mockup/`).

| Раздел | Что выбрано | Дата |
| --- | --- | --- |
| Токены · тёмная тема | Набор телефона (приглушённый текст 5,3:1 на карточке); по умолчанию, ответ «делай по плану» | 19.10.2026 |
| Токены · мелкий янтарный текст | `#A35704` (мокап, 4,75:1) вместо `#B5720A` (PLAN §4, 3,47:1); по умолчанию | 19.10.2026 |
| Токены · радиусы | 4 / 12 / 16 / 20 / 24 / 28 + pill; по умолчанию | 19.10.2026 |
| Токены · шрифты | Роли с точными размерами мокапа, полупиксели сохраняем; телефон: h1 34, h2 27, h3 19; по умолчанию | 19.10.2026 |
| Токены · стекло в lite | Непрозрачный фон 95 % без blur; в full — blur 18 px, saturate 1,4; по умолчанию | 19.10.2026 |
| Анимации · размытие | Анимированный `filter: blur` из мокапа заменяется на `opacity` + `transform` во всех режимах | 19.10.2026 |
| Эффекты · Э1 линии колонок | B — только на публичном сайте; в кабинете и `/dev` нет. 6 колонок по сетке 1280, пунктир, затухание сверху и снизу; телефон — 3 линии | 19.10.2026 |
| Эффекты · Э2 стекло | A — как в мокапе: blur 18 px, saturate 1,4, фон 84 % (светлая) / 72 % (тёмная); шапка прозрачна над обложкой, стекло после прокрутки; в lite — непрозрачный 95 % | 19.10.2026 |
| Эффекты · Э3 подсветка за курсором | A — заливка (380 px, янтарь 12 %) + светящийся край (260 px); только full и мышь; координаты не чаще кадра | 19.10.2026 |
| Эффекты · Э4 зерно плёнки | B — статичное, только full (3,5 % multiply в светлой, 5 % overlay в тёмной) | 19.10.2026 |

| Шапка · размеры | Как в мокапе: 68 px (≤ 980 — 60 px, телефон — 56 px); пункты 14 px / 550, активный — пунктир янтарём; логотип 17 px / 700, знак 30×23; круглые кнопки 42 px (телефон 44); «Показать телефон» — пилюля 36 px | 19.10.2026 |
| Шапка · Ш1 наведение | A — перекат букв (18 мс между буквами, 0,55 с) + остальные пункты гаснут до 45 %; в lite — только цвет ≤ 200 мс | 19.10.2026 |
| Шапка · Ш2 логотип | A — знак + «Vodiy House», лёгкое янтарное свечение знака | 19.10.2026 |
| Шапка · Ш3 язык | A — сегмент RU \| UZ; в меню телефона — «Русский \| O‘zbekcha» | 19.10.2026 |
| Шапка · Ш4 меню 761–1279 | A — выпадающий список под шапкой, строки 48 px, пунктирные разделители | 19.10.2026 |
| Шапка · Ш5 меню телефона | A — пункты десктопа + «Подбор за 1 минуту» (01–07), вид мобильного мокапа: стрелки, контакты VH, язык, тема, «Вход для сотрудников», политика | 19.10.2026 |
| Шапка · Ш6 шапка телефона | A — поверх фото белые иконки на тёмных кружках + затемнение; после прокрутки стекло и название страницы вместо «Vodiy House»; избранное, позвонить, меню, на внутренних — «назад» | 19.10.2026 |
