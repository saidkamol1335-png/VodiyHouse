## Решения исполнителя по ходу (без вопросов, по CLAUDE.md)
- Фазы A–B — `docs/progress/project2-phase-a.md`. Фаза C: кабинет переносится копией кода сайта с очисткой по графу; общие модули сайта и кабинета (модели страницы ЖК, UI-примитивы, DEMO калькулятора) пока живут копиями в обоих приложениях — сведение в `packages/shared` после фазы D, когда станет ясно, что из интерфейса кабинета остаётся. - 2FA руководителя (п. 8) в базе — механизм выбрать в интервью фазы D: TOTP с секретом на сервере и кодом от бота (бесплатно), телефонный фактор Supabase через Send SMS Hook (платная надстройка Advanced MFA) или своя таблица подтверждённых сессий на 30 дней. Черновик `docs/drafts/phase-d/head_second_factor.sql` вернуть в миграции новым номером только вместе с экраном кода в админке. 160000 и 170000 — в облако после пуша и деплоя (да исполнителя 02.11); 180000 — нет.
- `npm run mockup:*` — в корне (мокап в `docs/`). e2e сайта: порт dev-сервера берётся из `E2E_PORT` (порт 3000 на ноутбуке занят Acer PredatorSense — e2e на 3002: `E2E_PORT=3002 npm run e2e:1440 -w @vh/site -- <спека>`).
- Фаза C, п. 17: «телефон» = `(max-width: 767px), (max-height: 500px) and (pointer: coarse)` — лёжа тоже постер; низкое окно и крупный масштаб на компьютере — с роликом, как раньше (находка ревью Workflow). Решение — одно на показ страницы, как у ленты: масштаб посреди страницы первый экран не перестраивает. Файлы `hero-portrait.*` пока не удалены: вернуть ролик телефону — одна опция `posterOnPhone`.
- Netlify кабинета: вход Netlify (SSO команды) — только для не-production, как у сайта; иначе Telegram, вебхук заявок и расписание получали 401. Плагин `@netlify/plugin-nextjs` 5 — как у сайта (без него деплой отдавал 404 Netlify).
- Lighthouse из этого окружения: chrome-launcher не стартует Chromium (spawn UNKNOWN) — `lh-run.mjs` поднимает Chromium Playwright с портом отладки и зовёт Lighthouse с `--port` (асинхронно: синхронный вызов вешает браузер).

- Ревью C (низкое, не сделано): токен предпросмотра многоразовый 15 минут и лежит в адресе (история браузера, логи) — одноразовый обмен на cookie, если понадобится.
